# CS350
Thermostat

Summarize the project and what problem it was solving.

The final project focused on building a thermostat while learning more broadly about embedded systems. I wrote code to read the temperature, let the user adjust the setpoint and switch between heating, cooling, and off modes, and display the system’s information on an LCD. I also used a UART connection to send thermostat data between the Raspberry Pi and another device.

The project addressed the need for a simple way to monitor and control a room’s temperature. It also gave me hands-on experience combining hardware and software, including buttons, a temperature sensor, an LCD, and serial communication.


What did you do particlarly well?

I think I did particularly well with the coding in this project. I learned how to use Python to respond to button presses and display thermostat readings on the LCD. I also organized the code around the thermostat’s different states, which helped the system respond correctly when its settings changed. The code could still be improved, but I’m proud of how I brought the different parts together.

Where could you improve?
 
I could improve my understanding of the wiring involved in embedded systems. Learning to code while also working with traditional wiring could help me build a broader and more practical skill set. I’d like to get more comfortable identifying components and connecting them correctly before I start coding. That would also help me troubleshoot problems more confidently when the hardware and software need to work together.

What tools and/or resources are you adding to your support network?

Raspberry Pi configured as a general-purpose Linux system, UART communication, and I²C communication.

What skills from this project will be particularly transferable to other projects and/or course work?

The ability to work in a Linux-based environment will be useful in many future projects. I also gained experience using a Raspberry Pi as a hub for connected components and working with it through a server connection. The project taught me to build software around different system states, such as heating, cooling, and off, and gave me a foundation in embedded systems, where energy and other hardware limits can shape how a solution is designed. I can also apply what I learned about Python, button inputs, LCD displays, and UART communication in future coursework.

How did you make this project maintainable, readable, and adaptable?

I made the project easier to read by adding comments that explained the code and helped me keep track of what needed to happen next. I also started early so I had time to troubleshoot the wiring and make adjustments if needed. This gave me more room to update the project as I worked through it.
